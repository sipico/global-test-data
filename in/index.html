🇮🇳 India भारत (Bhārat)

India's best official test data are sandbox values: GSTINs listed for testing on NIC's e-invoice API developer portal, and test Aadhaar numbers that UIDAI publishes for its staging environment. The NIC portal could not be fetched directly, so the GSTINs were confirmed through search-engine extracts and a GSP's documentation. No authority reserves phone numbers, domains, PIN codes or company numbers for fiction, and no open API exists to check that a PAN or GSTIN is unused. India has no UBL: its e-invoice is a GSTN JSON schema, so only the identifiers carry over. Left out as unverified: the e-Way Bill sandbox GSTIN 05AAACG2140A1ZL (secondary sources only, PAN owner unknown), GSTINs derived from made-up PANs (no collision check possible), and the unregistered but unreserved domain example.in.

Identifier rules

Formats and check algorithms. Validators live in tools/checks.py.

IdentifierFormatValidatorAuthorityUBL
GSTIN (GST identification number)

Check character is Luhn mod-36 over the first 14 characters. GSTN has not published the algorithm; the rule used is python-stdnum's.

15 characters = 2-digit state code + PAN + entity number (1–9, A–Z) + Z + check characterin-gstinGSTN / CBICcac:PartyTaxScheme/cbc:CompanyID
PAN (Permanent Account Number)

The check-letter algorithm is undocumented; validators check shape and holder type only. Since DGFT Trade Notice 09/2017 the importer-exporter code (IEC) equals the PAN.

AAAAA9999A: 3 letters, holder-type letter (A B C F G H J L P T), initial of name, 4-digit serial, check letter—Income Tax Department—
Aadhaar (UID)12 digits, first digit not 0 or 1, Verhoeff check digitin-aadhaarUIDAI—
CIN (Corporate Identity Number)

No checksum. No MCA-published example was found.

21 characters: L/U + 5-digit NIC 2008 activity code + 2-letter state + 4-digit year + 3-letter class (PTC, PLC, OPC…) + 6-digit ROC number—Ministry of Corporate Affairs (MCA)—
LLPINAAA-9999—Ministry of Corporate Affairs (MCA)—
