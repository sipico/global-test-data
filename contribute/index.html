Contribute

The data set grows through pull requests. A value is accepted only with a source that shows it is reserved or published for examples, or with a documented check that it is unassigned.

What qualifies

  • Reserved — a regulator, registry or standard formally reserves the value or range (e.g. phone numbers for drama, GS1 prefix 952).
  • Official example — an authority uses the value in its own published examples, and it passes the official format and check rules.
  • Derived — built from the official rules and checked against the official register to be unassigned. State which register and the date.
  • Avoid — a value that circulates as an "example" but belongs to a real entity or fails validation. These warnings are just as valuable.

How

  1. Edit or add data/<country>.yaml (copy the structure of fr.yaml; schema in schema/country.schema.json).
  2. Give every entry at least one source with a URL, preferably the authority's own page or document.
  3. List the validators the value must pass under checks. Add a validator to tools/checks.py if the identifier type is new.
  4. Run pip install pyyaml jsonschema and python tools/validate.py — it must report 0 errors. The pull request runs the same check.
  5. Open a pull request. No code? Suggest a value in an issue instead.

Full guide: CONTRIBUTING.md. Contributions are published under CC0 1.0.
