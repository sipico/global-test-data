🌐 Global / international

Identifiers that are not tied to one country. Truly reserved values exist for ISO 3166 user-assigned codes, ISO 4217 XTS, ICAO "Utopia" (UTO), GS1 prefix 952, SWIFT test-and-training BICs and the IETF/IANA documentation ranges (domains, IPv4/IPv6, AS numbers, MAC addresses). No reserved range exists for LEI, ISBN, ISSN, DOI, IMO numbers, ISO 6346 owner codes, VIN, IATA codes, ISO 6523 ICDs or E.164 country codes. Payment-card test numbers are published by the card schemes' acquiring/gateway businesses, not by ISO or EMVCo. Candidate container numbers (ZZZU/XXXU/QQQU), IMO 0000000 and VIN 11111111111111111 pass their check digits but were not checked against any register, so they are not listed. Note that Peppol / EN 16931 country code lists contain no user-assigned code except XI.
