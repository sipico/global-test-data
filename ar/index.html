🇦🇷 Argentina

Argentina has little official test data. ARCA (formerly AFIP) publishes no shared test CUIT; its e-invoicing developer manual only uses example CUITs such as 30000000007 and 20111111112, plus the meaningful "No Categorizado" value 23000000000. None of these can be checked against the tax register (no open padrón lookup). E-invoices are SOAP web service requests (WSFEv1), not UBL. The BCRA gives the CBU check-digit rule but no example number, the CBUs found online use real bank codes, and ENACOM reserves no telephone numbers for fiction. No official test DNI exists.

Formats and check algorithms. Validators live in tools/checks.py.

CUIT / CUIL

Prefixes 20/23/24/27 = persons, 30/33/34 = legal entities. Weights 5-4-3-2-7-6-5-4-3-2, DV = 11 − (sum mod 11), 11 → 0; a result of 10 switches the prefix to 23/33. No ARCA primary source for the algorithm was found.

11 digits, 2-digit type prefix + 8-digit DNI or serial + check digit; written NN-NNNNNNNN-Nar-cuitARCA (formerly AFIP)—

CBU / CVU

Each DV is mod 10 with weights 9-7-1-3 (Com. "A" 2622). CVU (Com. "A" 6510) uses prefix 000 + 4-digit PSP code. No validator exists yet in tools/checks.py.

22 digits, entity (3) + branch (4) + DV, then account (13) + DV—Banco Central de la República Argentina—
CPA (Código Postal Argentino)

Province letter as in ISO 3166-2:AR (C = CABA, B = Buenos Aires province, X = Córdoba).

A9999AAA, province letter + 4-digit postcode + 3-letter block-face code, written left of the locality—Correo Argentino—
