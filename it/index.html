🇮🇹 Italy Italia

Unlike France, Italy has no official source of fictitious identifiers that also pass validation. The tax agency's FatturaPA examples use VAT numbers that fail the check digit, and the Treasury's NSO UBL order examples use real public bodies (MEF, Sogei, Consip). Partita IVA candidates built with a valid office code and check digit (e.g. 00000010587) were not found in VIES, but they have not yet been checked in the Agenzia delle Entrate "Verifica partita IVA" service, so they are not listed as usable values. No reserved fictional telephone range was found in AGCOM material: do not invent Italian numbers. There is no fictitious town or postcode (CAP), and no official open CAP dataset.
